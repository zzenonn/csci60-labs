# Slides

`intro-to-containerlab.bento.html`: *CSCI 60: Introduction to Containerlab*,
the lecture that goes with [Getting Started](../getting-started/README.md) and
the [sample topologies](../topologies/README.md).

Open the file in any browser. It is a [Bento Slides](https://bento.page) deck:
arrow keys move between slides, **F** goes fullscreen, **S** opens the
speaker view with notes, and **Esc** opens the editor. Save your edits with
**Ctrl/⌘ S**.

The deck uses the [DISCS Bento template](https://github.com/zzenonn/discs-bento-template).
`build_intro.py` rebuilds it from code with that template's tools:

```bash
python3 slides/build_intro.py ../discs-bento-template slides/intro-to-containerlab.bento.html
```
